## Root cause

`aeon.desktop.runtime._generate` emits a `TEXT_DELTA` event per step by
calling `tok.decode(generated_ids[-1:])` — a per-token decode. The
SentencePiece unigram vocabulary encodes leading spaces with the
`▁` metasymbol. When decoded in isolation, each piece produces its
own text without the leading space. Concatenating those isolated
decodes drops every word boundary. `scripts/run_p0_pipeline_proof.py`
has the same per-token concat pattern in its ad-hoc smoke path.

The one-shot decode `tok.decode(all_ids)` correctly reproduces the
canonical text.

## Independently: the P2 checkpoint's whaling fixation is visible here

Unrelated prompts ("The", "Hello world") both collapse into whaling
repetition. That IS a language-acquisition failure — it will be
addressed by the training tranche (Stage 1 mixture with single-book
and single-author caps), NOT by the renderer fix.

**No decoding trick, prompt trick, output rewrite, or template will
be introduced by the renderer fix.** The renderer fix corrects only:

  D_stream(y) = D_full(y)

It does not add missing words, repair grammar, change token choices,
or conceal repetition or the whaling fixation.
